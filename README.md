# zenithtune
=
 Zenith
A high-performance PC optimization and telemetry suite featuring a cyberpunk minimalist interface, real-time metrics, and direct Windows system adjustments.

Features
Real-Time Telemetry: Live monitoring for network latency, packet loss, CPU utilization, and memory pressure with a live frequency waveform.

Kernel & Registry Tweaks: Injects low-level optimizations to bypass network throttling and elevate GPU scheduling priorities.

Service Annihilator: Stops and disables background Windows telemetry data collection daemons.

Driver Auditor: Scans active motherboard and hardware controller driver signatures.

Integrated Audio: Atmospheric background audio looping.

Requirements
Windows 10 / 11

Python 3.8+

Installation & Running
Install dependencies:

Bash
pip install psutil pygame
Place your wbo.mp3 audio file in the project folder alongside zenith_hypercore.py and run.bat.

Right-click run.bat and select "Run as administrator" to launch the application with the required permissions for kernel modifications.
